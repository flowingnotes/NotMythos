Usage notes

The model

Coding Agent helps you read, write, and revise code. It doesn’t run the code it writes or open files on your device. Check its reasoning, then run your own tests.

The host operator chooses the base model and any fine-tuned adapter. A model’s own description of its performance is not a benchmark.

Conversation history

Completed turns are stored on the AI host, not in your browser. This browser stores a session key to reopen its threads. Use a separate browser profile or a private window on a shared device.

Sessions expire after 30 days by default. Deleting a thread removes it from your history. Clearing this site’s browser data removes your key and access to those threads. Don’t submit credentials or material you aren’t allowed to share with the host operator.

Host availability

The host processes one response at a time. If it’s working on another response, you’ll see your position in line. You can stop your own request, or reopen the same thread if your connection drops.

If the queue is full, wait and send again. If the host is offline, check its status on the overview or contact the operator.

Web references

When the operator enables web lookup, selected queries are sent to a search provider. The host uses result snippets, not the contents of pasted URLs. Turn Web off before sending anything you don’t want used as a search query, and verify any reference before relying on it.
