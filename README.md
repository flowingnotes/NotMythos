# Coding Agent website (static)

1. Create a GitHub repo, upload **everything in this folder** (drag the files in; keep the `assets` folder).
2. Repo **Settings -> Pages -> Build and deployment -> Deploy from a branch -> `main` / `(root)` -> Save**.
3. Open `https://YOURNAME.github.io/REPO/`.

The page is only an interface. The model runs on your own computer:
run `./launch.sh serve` in the project, and the site connects to `http://localhost:8000`
(use Chrome/Edge/Firefox; Safari blocks https->localhost requests).
If the address differs, click **Server** on the chat page.
